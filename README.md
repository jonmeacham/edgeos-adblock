# edgeos-adblock

`edgeos-adblock` is an ad-blocking updater for Ubiquiti EdgeOS routers. It
reads `service dns forwarding adblock`, loads
the configured local or HTTP sources, writes dnsmasq fragments, removes stale
fragments, and restarts dnsmasq.

## Install

Build the Debian package for the router architecture, copy it to the router,
and install it with `dpkg`:

```bash
make pkg-mips     # ER-Lite and other mips64 routers
make pkg-mipsel   # ER-X and other mipsle routers
scp dist/edgeos-adblock_*.deb admin@router:/tmp/
ssh admin@router 'sudo dpkg -i /tmp/edgeos-adblock_*.deb'
```

The package installs:

- `/config/scripts/edgeos-adblock`;
- EdgeOS configuration templates for `service dns forwarding adblock`;
- package installation and removal hooks.

On a new installation, the package creates a daily EdgeOS task-scheduler job
and configures the HaGeZi Pro dnsmasq list as the initial source.

## Configure

Use the normal transactional EdgeOS configuration workflow:

```text
configure
set service dns forwarding adblock dns-redirect-ip 0.0.0.0
set service dns forwarding adblock source ads description 'Example hosts source'
set service dns forwarding adblock source ads prefix '0.0.0.0 '
set service dns forwarding adblock source ads url 'https://example.invalid/hosts.txt'
set service dns forwarding adblock allow 'telemetry.example.com'
set service dns forwarding adblock block 'ads.internal.example'
commit
save
exit
```

Each source uses exactly one `url` or `file`. Inputs are normalized to domain
names, so the configuration does not distinguish hosts files, domain lists, and
dnsmasq lists. `allow` removes a domain and its descendants from generated
blocking, while `block` adds a domain without a source.

See [`docs/configuration.md`](docs/configuration.md) for the complete schema,
defaults, validation rules, input formats, and generated-file behavior.

Run an update manually with:

```bash
sudo /config/scripts/edgeos-adblock
```

Public command options:

```text
-dir <dir>  write dnsmasq fragments to another directory
-f <file>   read an explicit EdgeOS configuration file instead of the live CLI
-h          show help
-v          print progress to the terminal
-version    show build information
```

Generated files use the suffix `.edgeos-adblock.conf` under
`/etc/dnsmasq.d`. Package removal deletes the EdgeOS node, scheduler job, and
all fragments generated by the tool.

## Develop

Docker and GNU make are the only host prerequisites. The Makefile is the
contributor interface:

```bash
make help
make check      # complete CI-equivalent verification
make guard-makefile
make lint       # gofmt check and go vet
make test
make build
make pkgs
```

Artifacts are written to `dist/`. See
[`docs/build-and-test.md`](docs/build-and-test.md) for target and build-variable
details and [`docs/makefile-conventions.md`](docs/makefile-conventions.md) for
the repository's Makefile conventions.
